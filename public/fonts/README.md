# Fraunces — alternativa temporária de display

Família: Fraunces (The Fraunces Project Authors).
Origem oficial: https://github.com/google/fonts/tree/main/ofl/fraunces
Licença: SIL Open Font License 1.1, íntegra em `Fraunces-OFL.txt`.

As faces variáveis normal e itálica foram convertidas dos TTF oficiais para WOFF2. Glifos e eixos preservados. Não se trata da Bringbold Nineties. A substituição pela família original exige seus arquivos autorizados e licença web.

Configuração de uso: `src/styles/typography.css`.
